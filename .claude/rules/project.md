# Project conventions
- Use English for file names, function names, variables, types, and npm scripts.
- Keep README.md, user-facing guidance, and the interface in Spanish.
- Never change fixture values to make a failing check pass.
- Read the relevant source, agree on a plan, and request authorization before editing.
- This workshop extends Orbit with a report view in React/TypeScript. Follow docs/report-brief.md; do not ask the learner to choose a web or data route.
- Preserve existing segment AND status filters, API, table and fixture values. New report metrics, summary and CSV must use the same selected rows and integer cents.
