# Reglas de interfaz

Lee DESIGN.md y docs/references/ui.md antes de cambiar la interfaz.
Reutiliza componentes, colores, tipografía y paneles laterales existentes.
Usa HTML semántico, etiquetas visibles y controles que funcionen con teclado.
Devuelve el foco al control de apertura cuando cierres un panel.
Muestra errores junto al formulario y conserva los datos para reintentar.
Documenta las funciones públicas con JSDoc y nombres claros.
