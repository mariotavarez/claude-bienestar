# Sesión 1 de Bienestar GS

## Proyecto
Panel React y TypeScript con seis operaciones ficticias en fixtures/operations.json.
La aplicación se abre en http://127.0.0.1:4180 desde el equipo del participante.

## Cómo trabajar
- Primero lee los archivos relacionados y explica tu plan.
- Trabaja en un cambio pequeño y muestra el diff.
- Conserva los datos de práctica y el significado de los importes.

## Comandos
- npm run start abre la aplicación.
- npm test contrasta el filtro con cuatro resultados esperados.
- npm run check muestra cantidades, IDs e importes del filtro actual.
- npm run evidence guarda una observación con fecha y huella del archivo.
- npm run data resume la misma fuente con Python.
