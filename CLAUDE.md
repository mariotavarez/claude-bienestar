# Reglas de Orbit

- El laboratorio debe abrir al hacer doble clic en index.html. Conserva HTML, CSS y JavaScript clásico, con archivos relativos y sin dependencias ni peticiones de red.
- Usa las operaciones ficticias que recibe renderReport. No cambies la fuente de datos, el menú ni los filtros existentes para hacer que el reporte pase.
- Filtra y suma en centavos enteros. Convierte a MXN solo al mostrar o exportar.
- Explica qué archivos tocarías antes de editar y limita el diff al objetivo acordado.
- Usa pruebas.html para comprobar las funciones. Distingue resultados ejecutados en navegador de comprobaciones pendientes. Pide revisión manual para navegación, teclado, copia y descarga.
