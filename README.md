# Claude para programadores · Bienestar GS

Laboratorios del curso impartido por **Mario Josue Tavarez Mendoza · Mentor9**, con Imaginatec.

## Comienza por el módulo 1

Selecciona la rama **[modulo-1](https://github.com/mariotavarez/claude-bienestar/tree/modulo-1)** para abrir el laboratorio de React, TypeScript, Python y Claude Code. Esta rama incluye el README paso a paso y el Dev Container actualizado para VS Code.

```bash
git clone --branch modulo-1 https://github.com/mariotavarez/claude-bienestar.git
```

En GitHub Desktop: **File > Clone repository > URL**; pega la dirección del repositorio y selecciona **modulo-1** en **Current branch**. Abre esa carpeta en VS Code y sigue el README.

También puedes [descargar el ZIP del módulo 1](https://github.com/mariotavarez/claude-bienestar/archive/refs/heads/modulo-1.zip). Clonar con GitHub Desktop o Git es la ruta recomendada para seguir las actualizaciones.

## Qué necesitas

- GitHub Desktop o Git para clonar y elegir la rama.
- **Dev Container recomendado:** Docker Desktop, VS Code y Dev Containers. Node, npm, Python, Git y Claude Code vienen en el contenedor del módulo 1.
- **Instalación manual:** VS Code, Node 24 compatible con el laboratorio, npm, Python 3, Git y Claude Code. El README explica cada comando por separado.
- Acceso propio o corporativo compatible a Claude Code para trabajar con el agente real. El acceso al aula es independiente.

En la [plataforma Imaginatec](https://imaginatec.tech/aula/#instalacion), selecciona el curso **Bienestar GS** y abre **Instalación** para consultar las guías por herramienta y sistema operativo. Se requiere tu acceso al curso.

## Cómo funciona la práctica

El módulo 1 contiene un **defecto intencional** en el filtro de Orbit. Las pruebas iniciales de segmentos específicos fallan hasta que lo investigues y corrijas. El README explica el comportamiento inicial, el resultado esperado y cómo conservar evidencia.

Trabaja con los datos ficticios incluidos. Conserva tus cambios en una rama propia antes de actualizar o cambiar a otro módulo. Para dudas de clase usa **Preguntas y problemas** de la plataforma.
